This is a student project created for educational purposes and is not an official or affiliated website.

The goal of this project is to create a responsive webpage that is flexible and works across different screen sizes. At the time of writing this, it seems likely, that the final product will be a buggy mess that may not work on as many screen sizes as planned. I realise I need more practice with making websites functional on different resolutions.

Some players are missing due to the Premier League website not having assets for them available, so instead of breaking the theme, I omitted them entirely.

Just in case I deliver a buggy mess that does not function properly: I could probably have vibe coded a functional design using LLMs, but I didn't want to add any code that I didn't at least partially understand. I have used LLMs to explain concepts, but the purpose has been to learn, every time, not copy the code it spews out.

I wanted to add tooltips to all the flags, so they would show the country name when hovered over, but put it far down on the priority list.
